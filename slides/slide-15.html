IT'S JUST CSS

“It renders now. But it's only CSS — worst case, it looks a bit ugly.”

Can we go on holiday now?

First containment beat. The naive assumption, stated with confidence: CSS only decides how things look, so the worst case is cosmetic. Ask the room, then advance to the No, which shows that "how things look" is exactly the attack — the page can lie. No data leaves on this one; it's pure deception. ~10 seconds on this slide.
