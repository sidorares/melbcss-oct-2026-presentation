CSP BLOCKING EVERYTHING

A font-height oracle + :has() + inset exfiltrates a numeric token on one click. Zero external requests.

You can block the network and the data still walks out — encoded in which link the victim happens to click.

“Block external requests” assumes exfiltration needs a request. It doesn't.

This defeats the strongest instinct a backend dev has: cut the network and you're safe. Two defeats. LEFT: image proxies (which rewrite/forward image URLs to hide your IP) get bypassed with CSS escape tricks and allow-listed domains, so attackers still confirm an email was opened. RIGHT: the real mind-bender from PortSwigger — even with a CSP that blocks ALL external resources, you can exfiltrate by making the correct link full-screen (inset) and every wrong link off-screen, measuring digits with a font-height oracle, so a single victim click sends the token. No request leaves until the click, and it's to a link, not a blocked resource. ~65 seconds. The next slide breaks down exactly how the no-request version works.
